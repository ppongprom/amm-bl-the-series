# ชั้น 14 มีรัก — Continuity Bible

## กฎสมจริง 100%

- ห้ามมีเหตุการณ์ที่เป็นไปไม่ได้ในออฟฟิศจริง

- เกินจริงได้เฉพาะในจินตนาการ/ฝัน ของตัวละคร (ต้องชี้ชัดว่าเป็นจินตนาการ)

- Timeline ต้องไหลลื่น ไม่ย้อน ไม่กระโดด โดยไม่มีเหตุผล

- ทุกตอนต้องไม่ขัดแย้งกับข้อเท็จจริงที่ตั้งไว้ในตอนก่อน

## Setting: PRISM Creative Agency

- ตึกกระจก 14 ชั้น ทองหล่อ กรุงเทพฯ

- เอเจนซี่โฆษณา/ครีเอทีฟ

- มีห้องประชุมใหญ่ ห้องประชุมเล็กหลายห้อง

- ชั้น 14 = ชั้นทำงานหลัก (ออฟฟิศเปิด open plan + ห้องผู้บริหาร)

- มีห้องครัว/pantry ส่วนกลาง

- มีดาดฟ้า (ชั้น 14 เป็นชั้นบนสุด)

- ห้องเซิร์ฟเวอร์ (IT)

## Timeline

- ตอน 1: วันจันทร์ สัปดาห์ 1 — วันแรกของไอซ์ (ปอนด์เป็น intern มาสองสัปดาห์แล้ว)

- ตอน 2: วันพุธ สัปดาห์ 1 (เช้า) — ปอนด์ใช้ AI compile research → ภูมิสอน cross-check

- ตอน 3: วันพุธ สัปดาห์ 1 (บ่าย) — วันเดียวกับตอน 2 → กาแฟ 25 บาท + สมุดจด

- ตอน 4: วันศุกร์ สัปดาห์ 2 (เช้า-บ่าย) — เจมส์×ฟลุ้ค ทะเลาะ→ร่วมมือ

- ตอน 5: วันศุกร์ สัปดาห์ 2 (เย็น-ค่ำ) — วันเดียวกับตอน 4 → after-work + BTS

- ตอน 6: วันอังคาร สัปดาห์ 3 — เต×แทน เตสังเกตแทนซ่อมคอมให้คนอื่นแต่คอมตัวเองพัง → คุกกี้+โน้ต

- ตอน 7: วันพฤหัสบดี สัปดาห์ 3 (ค่ำ) — ดิว×นนท์ OT คืนแรก → แชร์หูฟัง ดิวหลับพิงไหล่

- ตอน 8: วันศุกร์ สัปดาห์ 3 (เช้า) — คิม×ไอซ์ + ภูมิ×ปอนด์ ประชุมร่วม 2 ทีม → ปอนด์ present + insight "กลัวไม่เข้าพวก" → ภูมิ "ดี ที่ cross-check" → ไอซ์ยิ้มรู้ทัน → คิม "ยิ้มอะไร?" → "แค่เห็นคนเหมือนกัน"

- ตอน 9: วันอังคาร สัปดาห์ 4 (เย็น) — เจมส์×ฟลุ้ค ฝนตกหนัก วินหยุดวิ่ง → เจมส์กั้นร่มให้ เอียงไปฝั่งฟลุ้ค ไหล่ขวาเปียก → ฟลุ้ควางผ้าเช็ดหน้าบนไหล่เจมส์ → "คืนวันไหนก็ได้" → เตเห็นสองคนออกไปใต้ร่มเดียว

- ตอน 10 (จบ Part 1): วันศุกร์ สัปดาห์ 4 (เย็น) — เต×แทน + ดิว×นนท์ "เห็นแล้วยิ้ม" — เตเอาข้าวเหนียวหมูปิ้งไปให้แทนที่ห้องเซิร์ฟเวอร์ → เล่าให้ฟังว่าเห็นดิว-นนท์นั่งพิงกันหลับ → แทนหลุดปากว่า "เคยเห็นมาก่อน" (callback ep07) → สองคนมองไปพร้อมกัน สบตากันเอง ยิ้มพร้อมกัน (**ผีเห็นผี ครั้งแรกที่เป็นความรู้สึกร่วมของ เต×แทน เอง**) → เตชวนไปกินข้าวเย็นด้วยกัน แทนตอบ "ได้" → ไอซ์เห็นสองคนเดินไปด้วยกันที่ลิฟต์ → คิมรอไอซ์แล้วไปด้วยกัน → ภูมิบอกปอนด์พักผ่อนวันเสาร์ → เจมส์เก็บผ้าเช็ดหน้าที่ซักแล้ว ตั้งใจคืนวันจันทร์ → ดิวตื่นถามว่าทำไมไม่ปลุก นนท์ตอบ "ไม่อยากปลุก" (ยอมรับตรงๆ ครั้งแรก ต่างจาก ep07 ที่โกหกว่า "ไม่นาน")

**📍 Part 1 "สายตาที่ซ่อนไว้" จบที่ตอน 10 — ทั้ง 5 คู่เปิดจุดเริ่มต้นครบแล้ว (ตอน 11 เป็นต้นไป = Part 2 "ผีเห็นผี" ตามเอาท์ไลน์ story-outline-expanded.md)**

## ตัวละคร — ข้อเท็จจริงที่ตั้งไว้แล้ว

### กฎพื้นหลังตัวละคร (Financial & Background)

- **พี่ๆ/หัวหน้า** (คิม, ภูมิ, เจมส์, ดิว): ฐานะดีจากการทำงาน — smart ฉลาด ไหวพริบดี มีผลงานโดดเด่น ทำให้ตำแหน่งมั่นคงและรายได้ดี แต่ไม่ถึงสายจ่ายฟุ่มเฟือย

- **น้องๆ/หน้าใหม่** (ไอซ์, ปอนด์, ฟลุ้ค, นนท์): เรียนมหาลัยดัง (จุฬา/ธรรมศาสตร์) ฐานะกลางๆ ค่อนไปทางพอมีพอกิน → สร้าง dynamic "พี่เห็นใจ/อยากดูแล"

- **เต**: HR ฐานะปานกลาง เป็นคนอบอุ่น เข้ากับทุกคนได้

- **แทน**: IT เงียบ ฐานะไม่ต้องพูดถึง (ไม่ใช่ประเด็น)

- ฐานะไม่ต้องพูดตรงๆ ในเรื่อง → สื่อผ่านรายละเอียดเล็กๆ (ข้าวกล่อง 45 บาท, กาแฟ 25 บาทมีค่า, ไม่มีรถส่วนตัว ขึ้น BTS)

### คิม — Creative Director

- อายุประมาณ 32-34

- เสื้อเชิ้ตขาว แขนพับ ปลดกระดุมบนสุด

- ประหยัดคำพูด ตอบสั้น "ได้"/"ไม่ได้"

- ไม่ได้เย็นชา แค่ไม่พูดเยอะ

- อ่านงานที่ส่งมาทันทีเสมอ (ให้เกียรติ)

- มีห้องทำงานส่วนตัว กระจกบังตาฝ้า

- present งานหน้าห้องประชุมได้ เสียงทุ้มชัด

- ฐานะ: ดีจากฝีมือ ไม่อวดรวย — สั่งอาหารพอดี ไม่ฟุ่มเฟือย (ตอน 3: ข้าวหน้าปลาย่างจานเดียว)

- \[ตอน 1\] หยิบขนตาออกจากแก้มไอซ์ → ไม่สบตาหลังสัมผัส

- \[ตอน 7\] บอกไอซ์กลับก่อน "พรุ่งนี้มาเช้าหน่อยแทน" — ห่วงแต่ไม่พูดตรง

- \[ตอน 8\] present creative direction 3 แนวทาง, เห็นด้วยกับ insight ปอนด์ "น่าสนใจ ลองเอาไปขยาย", ถามไอซ์ "ยิ้มอะไร?" → ชะลอก้าวตรงมุมทางเดิน "เหมือนกัน... กับใคร?"

### ไอซ์ — เลขานุการผู้บริหาร (ใหม่)

- อายุประมาณ 23-24

- จบอักษรศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย

- โต๊ะอยู่ข้างนอกห้องคิม

- ใส่สูท (วันแรก)

- จดบันทึกประชุมเป็นหน้าที่

- สังเกตรายละเอียดเก่ง

- ฐานะ: กลางๆ พอมีพอกิน — กินข้าวกล่องราคาประหยัด ไม่ค่อยสั่งเพิ่ม

- \[ตอน 1\] วันแรก เจอคิม หน้าแดงหลังถูกสัมผัส

- \[ตอน 6\] นั่งหน้าห้องคิม เห็นเตเดินมาวางของที่โต๊ะแทน + เตแวบตามองโต๊ะแทน → "อีกคนแล้ว" (ผีเห็นผี ต่อจากตอน 3)

- \[ตอน 7\] คิมบอกให้กลับก่อน ไอซ์ยิ้ม "พี่คิมอย่าอยู่ดึกนะครับ" — ถาม "ไม่กลับเหรอ?" กับดิว+นนท์ก่อนออก

- \[ตอน 8\] จดบันทึกประชุม, สังเกตภูมิเลื่อนขวดน้ำให้ปอนด์ (เปรียบเทียบกับคิม), ส่ง minutes → ยิ้มโดยไม่รู้ตัว → คิมจับได้ → "แค่เห็นคนเหมือนกัน" (ผีเห็นผี double layer: ไอซ์เห็นภูมิ×ปอนด์, คิมเห็นไอซ์)

- \[ตอน 10\] เห็นเตกับแทนเดินมาด้วยกันตรงลิฟต์ ถามเผลอ "ไปด้วยกันเหรอคะ" → ยิ้มมุมปาก "อีกคู่แล้วสินะ" (ผีเห็นผี), คิมรอแล้วชวนกลับด้วยกัน "เดี๋ยวไปด้วยกัน"

### เต — ฝ่าย HR

- อายุประมาณ 28-30

- สูงกว่าไอซ์เล็กน้อย

- ยิ้มง่าย เป็นมิตร อบอุ่น

- เป็นคนพาไอซ์ tour ออฟฟิศ

- ถือแก้วกาแฟ (ตอนเช้า)

- ตอน 1-5: ไม่ได้ไป after-work (ยังไม่สนิทกับกลุ่ม creative มากนัก / อาจมีงาน HR)

- **กลางเรื่อง (Part 2+):** เตจะกลับมาสนิทกับทุกคนมากขึ้น เพราะบทบาท HR ทำให้เจอคนหลากหลาย + come out ก่อนทุกคู่ทำให้เป็นที่ปรึกษา

- \[ตอน 1\] เห็นไอซ์หน้าแดงออกจากห้องคิม → ยิ้มมุมปาก ไม่พูดอะไร (ผีเห็นผี seed)

- \[ตอน 6\] สังเกตแทนซ่อมให้ฟลุ้ค ดิว แต่คอมตัวเองจอกระพริบ+เทปใส → เขียนโน้ต "ช่างคนอื่นบ้าง ดูแลตัวเองด้วย" + คุกกี้เนยจากร้านใต้ตึก วางที่โต๊ะแทนตอนไม่อยู่

- \[ตอน 9\] ยืนรอวินที่ล็อบบี้ เห็นเจมส์กับฟลุ้คเดินออกไปใต้ร่มเดียว → หยิบมือถือเปิดแชทแทน → ไม่ได้พิมพ์อะไร → ยิ้มนิดนึง → ล็อคจอ (ผีเห็นผี)

- \[ตอน 10\] เอาข้าวเหนียวหมูปิ้งไปให้แทนที่ห้องเซิร์ฟเวอร์ → เล่าเรื่องดิว-นนท์ → มองไปพร้อมกับแทน สบตากันเอง ยิ้มพร้อมกัน (ผีเห็นผี ที่เป็นของสองคนเองครั้งแรก) → ชวนแทนไปกินข้าวเย็นด้วยกัน แทนตอบ "ได้"

### แทน — IT

- อายุประมาณ 26-28

- เงียบกว่าคิม

- นั่งหลังห้องประชุม ซ่อมอะไรสักอย่างไปประชุมไป

- ตอน 1-5: ยังไม่ปรากฏตัวโดดเด่น (จะเปิดตัวหลักตอน 6)

- ยังไม่มีปฏิสัมพันธ์กับเตในตอน 1 (มีแค่กล่าวถึง)

- \[ตอน 6\] ซ่อม dock ให้ฟลุ้ค (จอมืด), ปรับ Figma สีเพี้ยนให้ดิว → ไม่เคยบ่นเรื่องจอตัวเองที่กระพริบ+มีรอยเทปใส → เจอคุกกี้+โน้ตจากเต → พับโน้ตเหน็บขอบจอ → ปรับ backlight จอหยุดกระพริบ → มุมปากขยับนิดเดียว

- \[ตอน 7\] เดินผ่านโซน creative ตอน 4 ทุ่ม เห็นดิวหลับพิงไหล่นนท์ → มือแตะโน้ตพับครึ่งในกระเป๋า (โน้ตจากเต) → ตาอ่อนลง → เดินผ่านไปเงียบ

- \[ตอน 10\] เตมาหาที่ห้องเซิร์ฟเวอร์ พร้อมข้าวเหนียวหมูปิ้ง → หลุดปากบอกว่า "เคยเห็น" ดิว-นนท์นั่งพิงกันมาก่อน (ครั้งใน ep07) → ลุกไปมองพร้อมเต สบตากันเอง ยิ้มพร้อมกัน → ตอบรับชวนกินข้าวเย็นด้วยกัน "ได้" (สั้นแบบเดิม แต่เป็นครั้งแรกที่ตอบรับชวนอะไรที่ไม่ใช่เรื่องงาน)

### ภูมิ — หัวหน้าทีม / Project Manager

- อายุประมาณ 30-32

- จริงจัง เสียงทุ้ม

- ดูแลลูกทีมแบบเงียบๆ ไม่พูดมาก แต่สังเกตทุกอย่าง

- ฐานะ: ดีจากผลงาน — ซื้อกาแฟเผื่อน้องได้ไม่คิดมาก (25 บาทไม่ใช่เรื่องใหญ่สำหรับเขา แต่ใหญ่สำหรับปอนด์)

- \[ตอน 1\] แนะนำตัวในห้องประชุม

- \[ตอน 2\] จำเวลาปอนด์มาถึง, ช่วยจัด research, สอน "cross-check กับต้นฉบับ"

- \[ตอน 3\] ซื้อกาแฟเย็น 25 บาท "ไม่ต้องขอบคุณ แค่ 25 บาท" + สังเกตว่าปอนด์ชอบซื้อร้านนี้

- \[ตอน 8\] เปิด brief ในประชุมร่วม, ให้ปอนด์ present competitive landscape, เลื่อนขวดน้ำให้ปอนด์เงียบๆ (ดูแลแบบไม่พูด), "ดี ที่ cross-check" (callback ep02), มุมปากขยับภูมิใจแต่ไม่แสดงออก

- \[ตอน 10\] เดินผ่านโต๊ะปอนด์ตอนเย็นวันศุกร์ บอก "พรุ่งนี้วันเสาร์ พักผ่อนบ้าง" แล้วเดินต่อ ไม่หยุดรอคำตอบ

### ปอนด์ — เด็กฝึกงาน (Intern)

- อายุประมาณ 21-22 (ปี 4)

- นิเทศศาสตร์ มหาวิทยาลัยธรรมศาสตร์ (ฝึกงานภาคบังคับ)

- นั่งถัดจากภูมิในห้องประชุม

- มีสมุดจดหนาปึก (ตั้งใจจด — character trait: จดทุกอย่างลง physical notebook แม้ยุค 2026)

- มาก่อนไอซ์ (ฝึกงานมาสองสัปดาห์แล้วตอนไอซ์เริ่มงาน)

- ฐานะ: พอมีพอกินแบบจำกัด — ซื้อข้าวกล่องราคาประหยัดปากซอย (~45 บาท), กาแฟเย็น 25 บาทที่ภูมิซื้อให้มีค่ามาก

- \[ตอน 2\] เขียนในสมุดจด (เล่มเดียวกับตอน 1): จด brief + cross-check

- \[ตอน 3\] เขียนในสมุดจด มุมล่างขวา: "ชอบเย็น ไม่ต้องขอบคุณ แค่ 25 บาท"

- \[ตอน 8\] present competitive landscape ในประชุมร่วม (เสียงเบาตอนแรก → มั่นคงขึ้นเมื่อเข้าข้อมูลที่ research มา), เสนอ insight "กลัวไม่เข้าพวก" → คิมเห็นด้วย, เขียนในสมุดจด: "ดี ที่ cross-check" (running gag: ep01/02/03/08)

- \[ตอน 10\] ภูมิเดินผ่านบอก "พรุ่งนี้วันเสาร์ พักผ่อนบ้าง" → เขียนอะไรบางอย่างสั้นๆ ในสมุดจดอีกครั้ง (ไม่เปิดเผยข้อความ — running gag ต่อเนื่อง)

### ฟลุ้ค — Copywriter

- อายุประมาณ 25-26

- ยิ้มกว้าง (คนแรกที่ไอซ์จำได้)

- พยักหน้าทัก

- นั่งตรงข้ามเจมส์

- บ้านอยู่อุดมสุข (BTS สายสุขุมวิท E12 — 6 สถานีจากทองหล่อ ไปทางเดียวกับเจมส์)

- ฐานะ: กลางๆ แต่ใจกว้าง — "ผมเลี้ยง" ตอน after-work (ไม่ได้รวย แต่อยากเฉลิมฉลอง)

- \[ตอน 6\] จอมืด (dock) → แทนมาแก้ให้ ยิ้ม "ขอบคุณ!"

- \[ตอน 7\] OT night → เจมส์บอกให้กลับก่อน "ส่งมาให้ผม review ทางไลน์ได้" → ฟลุ้คเก็บของตามเจมส์กลับ

- \[ตอน 9\] ฝนตก ไม่มีร่ม → เจมส์กั้นร่มให้ เดินจากล็อบบี้ไป BTS ทองหล่อ → ไหล่ตัวเองแห้งทั้งสองข้าง → วางผ้าเช็ดหน้าบนไหล่เจมส์ "เปียกอยู่" (ไม่ถาม ไม่รอ — mirror เจมส์) → "คืนวันไหนก็ได้" → พกผ้าเช็ดหน้าพับเรียบในกระเป๋า (character trait ใหม่)

- \[ตอน 10\] ไม่ปรากฏตัวโดยตรง — ผ้าเช็ดหน้าที่ให้เจมส์ยืมยังอยู่กับเจมส์ (เจมส์ซักแล้วตั้งใจคืนวันจันทร์)

### เจมส์ — Creative (Art Director ระดับ Junior-Mid)

- อายุประมาณ 27-29

- เงยหน้ามาแป๊บเดียวแล้วก้มกลับ (ดูจริงจังกับงาน)

- นั่งตรงข้ามฟลุ้ค

- บ้านอยู่อ่อนนุช (BTS สายสุขุมวิท E9 — 3 สถานีจากทองหล่อ)

- ฐานะ: มั่นคงจากฝีมือ — ไม่ฟุ่มเฟือย ไม่ขี้เหนียว (เปิดเมนูบังหน้าแทนตอบเรื่องส่วนตัว)

- \[ตอน 4\] "ใช้ได้" = ชมสูงสุด, เว้นที่ใน visual ให้ก็อปปี้โดยไม่บอก

- \[ตอน 5\] ยอมรับ "ดี" ครั้งแรก, พูดยาวที่สุดที่เคย → เรื่องก็อปปี้ของฟลุ้ค, "กลับดีๆ" ก่อนประตู BTS ปิด

- \[ตอน 7\] OT night — บอกฟลุ้ค "กลับเลย อันนี้ผมทำได้" ยืนรอจนฟลุ้คเก็บของ (ไม่เคยยืนรอ → ep05 callback)

- \[ตอน 9\] ฝนตก มีร่มพับ → กั้นให้ฟลุ้ค เอียงร่มไปฝั่งฟลุ้ค ไหล่ขวาเปียกโชก → "ก็นายตัวสูง ร่มมันไม่ถึง" (โกหก ตั้งใจเอียง) → ฟลุ้ควางผ้าบนไหล่ → "ขอบคุณ" เสียงเบากว่าปกติ → แตะผ้าบนไหล่เบาๆ ตอนฟลุ้คมองผ่านกระจก (proximity escalation: ep05 ไหล่ชน → ep07 ยืนรอ → ep09 ร่มเดียว/ผ้าบนไหล่)

- \[ตอน 10\] เย็นวันศุกร์ หยิบผ้าเช็ดหน้าของฟลุ้คที่ซักแล้วพับเรียบออกจากลิ้นชักโต๊ะ ตั้งใจคืนวันจันทร์ → มองแล้วยิ้มเบาๆ คนเดียว (proximity escalation ต่อ: เก็บของเขาไว้ดูแล้วยิ้ม)

### ดิว — Graphic Designer

- อายุประมาณ 26-28

- ใส่หูฟัง ก้มหน้าก้มตา (จดจ่อกับงาน)

- นั่งข้างนนท์

- ไม่ใช่คนอธิบายเรื่องส่วนตัว ตอบสั้น

- \[ตอน 4\] ไม่ถอดหูฟัง แต่ได้ยินเจมส์กับฟลุ้คทะเลาะทุกอย่าง → เสนอ "ลองทำคนละแบบ"

- \[ตอน 6\] ปัญหา Figma สีเพี้ยนหลังอัปเดต → แทนมาแก้ให้

- \[ตอน 7\] OT คืนแรก → นนท์แชร์หูฟังให้ → หลับพิงไหล่นนท์ → ตื่นมาพบว่าไฟล์ถูก save แล้ว

- \[ตอน 10\] OT อีกรอบ (คืนวันศุกร์) → พิงไหล่นนท์หลับอีกครั้ง (เตกับแทนเห็นจากระยะไกล) → ตื่นมาถามทำไมไม่ปลุก → นนท์ตอบตรงๆ "ไม่อยากปลุก" (ต่างจาก ep07 ที่โกหกว่า "ไม่นาน")

### นนท์ — Motion Graphic Designer

## กฎออฟฟิศยุค 2026

- ไม่ print เอกสารแล้ว — ส่งเป็นอีเมล/ไลน์/แชร์ไฟล์ดิจิทัล

- ใช้ AI ช่วยทำงาน (compile research, สรุปข้อมูล, draft ก็อปปี้) — แต่ต้อง cross-check เสมอ

- ประชุมมีทั้ง on-site และ online (แต่ PRISM เน้น on-site เพราะเป็น creative agency)

- สื่อสารผ่าน LINE กลุ่ม, อีเมล, และ project management tool

- สมุดจดกระดาษ = character trait เฉพาะตัว (ปอนด์) ไม่ใช่ norm ของออฟฟิศ

- Visual work: ใช้ดิจิทัลทั้งหมด (Figma, AI image gen, etc.)

- Pitch deck: present ผ่านจอ/โปรเจกเตอร์ ส่ง mock-up ทางไลน์/อีเมล

## กฎความยาว / Shorts Compatibility

- ทุกตอน: 800-1,200 คำ (อ่าน 3-4 นาที) — ไม่เกิน 1,500 คำ

- ต้อง Shorts-compatible: ตัดเป็นวิดีโอ 30-60 วินาทีได้

- ถ้าตอนยาวเกิน → แยกเป็น 2 ตอน (เช่น ตอน 3 แยกเป็น 3+4)

- ทุกตอนต้องมี: hook เปิด + emotional payoff + จบแบบอยากอ่านต่อ

- FB: 800-1,500 คำ \| IG Carousel: 8-12 สไลด์ (500-800 คำ)

## สิ่งที่ต้องระวังเมื่อเขียนตอน 2 (v2 — ยุค 2026)

- ปอนด์เป็น intern มาก่อนไอซ์ → ต้องรู้ออฟฟิศบ้างแล้ว แต่ยังเขินๆ เพราะยังใหม่

- ภูมิเป็นหัวหน้าทีม → ต้องมีเหตุผลที่ดูแลปอนด์ (เพราะปอนด์อยู่ในทีม)

- กินข้าวกลางวัน → ร้านข้าวแกงปากซอย (ข้าวกล่อง ~45 บาท สมจริงกับ intern ฐานะจำกัด)

## กฎการเดินทาง/Commute Realism (กรุงเทพ)

- บริษัทอยู่ลึกในซอยทองหล่อ → พนักงานนั่งวินมอเตอร์ไซค์จาก BTS ทองหล่อ (ไม่เดิน)

- ที่อยู่ตัวละครต้องห่างจากที่ทำงานอย่างน้อย 3-4 สถานี ถึงจะสมจริงว่า "ขึ้น BTS"

- สถานีที่อยู่ติดกัน (เช่น ทองหล่อ-เอกมัย) → คนจริงจะนั่งวินหรือเดิน ไม่ขึ้น BTS

- ต้องตรวจสอบว่าตัวละครที่ "ไปทางเดียวกัน" อยู่สถานีทิศทางเดียวกันจริง

- BTS สายสุขุมวิท (จากทองหล่อ ไปทิศตะวันออก): ทองหล่อ(E6) → เอกมัย(E7) → พระโขนง(E8) → อ่อนนุช(E9) → บางจาก(E10) → ปุณณวิถี(E11) → อุดมสุข(E12)

- BTS สายสุขุมวิท (จากทองหล่อ ไปทิศตะวันตก): ทองหล่อ(E6) → พร้อมพงษ์(E5) → อโศก(E4) → นานา(E3) → เพลินจิต(E2) → ชิดลม(E1) → สยาม(CEN)
